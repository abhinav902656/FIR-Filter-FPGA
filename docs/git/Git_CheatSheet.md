# Git Cheat Sheet

## Check Status

```bash
git status
```

## Add Files

```bash
git add .
```

## Commit

```bash
git commit -m "Describe your changes"
```

## Push

```bash
git push
```

## Pull

```bash
git pull
```

## View History

```bash
git log --oneline
```

## Check Remote

```bash
git remote -v
```
